# Introdução

Esse repositório possui o programa desenvolvido durante a matéria de Teoria de Programação Avançada, no sexto período do curso Bacharelado em Sistemas de Informação.

## Como rodar 

Para rodar o programa, clone o repositório, vá para o caminho `Trabalho > src > dominio > Main.java` e execute a função `main`. 
Se seguiu o caminho certo, no terminal aparecerá o menu criado pelo programa.
